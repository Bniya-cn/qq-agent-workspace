# 控制台静态资源

- `index.html` 保留原页面结构与控件；`panel.js` 包含原页面脚本和新增任务控件，`panel.css` 保存原样式；`theme.js` 必须在 Tailwind CDN 后、页面主体前加载。
- `/panel` 每次读取 HTML，兼容 `web_panel.PANEL_HTML` 字符串读取；静态文件仅通过 `/panel-assets/` 的固定文件名白名单提供，使用 `Cache-Control: no-store`。编辑这些资源后刷新页面即可，不需要重启 Python。
- 人设与业务仍由后端负责。前端设置按字段提交；轮询只读取状态，发布按钮仅提交一次任务，后续依据任务状态展示结果。
- 同 QQ 整轮串行、不同 QQ 独立是固定策略。历史与群缓冲开关仅影响快速聊天路径，不提供未经实现的并行输出开关。
- 定时发布需要显式启用，使用北京时间。网络断连/缺回执时显示未知且不自动重发；操作人核实后可解除手动重发限制，该操作本身不会发送消息。
- 浏览器验证避免点击真实发布按钮；离线用例位于 `bot/tests/test_persona_panel_daily.py`。
