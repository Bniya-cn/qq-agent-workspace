## 4. 1.85s 接缝专项

`seam_check_g3v2.json` 将 1.85s 标为 `boundary_start`（nospeech 去词后再接入的边界）。

| 文件 | energy_jump_db | flux | abnormal | 听感判断 |
| --- | ---: | ---: | --- | --- |
| src g3v2 | 7.45 | 0.964 | **true** (energy>p99) | 源本身有边界谷 |
| **dania s-3** | 10.99 | 0.896 | **false** | **无明显拼接咔哒；可过** |
| dania s-4 | **24.69** | **1.131** | **true** | **可听出拼接 → FAIL** |
| amiya s-3 | 7.43 | 0.916 | true (energy>p99) | 短空隙/吸气感，条件过 |
| amiya s-2 | 9.88 | 0.924 | true | 略重于 s-3 |

自算 10ms RMS 轮廓（1.70–2.00s）：各文件在 ~1.84–1.86s 均出现能量下凹，与源同型 → **根因是 nospeech 编辑边界，不是 Seed 独有撕裂**。达妮娅 s-4 下凹最深、抬升最猛，故唯独它硬 FAIL。

**验收结论**：首选达妮娅 s-3 **通过**第 4 项；阿米娅 s-3 **条件通过**（建议试听时专门听 1.8–2.0s）；备选达妮娅 s-4 **不通过**。

## 5. ASR「呃」循环专项（dania s-3）

| 证据 | 结果 |
| --- | --- |
| Whisper 文本 | 「呃」极长重复；vad=True 同样复读 |
| no_speech_prob | **0.603**（偏无语音） |
| avg_logprob | **-0.037**（异常高置信的复读） |
| 包络 ACF 80–500ms | 峰值仅 **0.56@80ms** 且单调衰减（音高相关，非卡顿周期） |
| 相邻 200ms 梅尔余弦 | max **0.972**，**frac>0.98 = 0**（无粘连重复块） |
| 150ms 波形互相关 | 最佳仅 **0.42**（非拷贝粘贴循环） |
| onset 周期性 | ~108ms，prominence 仅 2.5×（弱，且与源 9.26Hz 同类） |

**结论：ASR 幻觉，不是听感真循环/卡顿。** 第 3 项 **不因此 FAIL**。同类幻觉亦见于其它非词汇持续声（如 amiya g1ns s-3 的「呃」串）。
